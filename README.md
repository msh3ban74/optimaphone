# أوبتيما فون

**متجر مُنتقى للأجهزة** — موقع عربي بالكامل، من اليمين إلى اليسار، بواجهة داكنة
وفاتحة ولمسة ذهبية هادئة.

مبني بـ Vite و React و TypeScript في الوضع الصارم، بلا أي مكتبة واجهة جاهزة،
وبلا أي اتصال بجهة خارجية.

---

## أولًا: أضف بضاعتك

المتجر يبدأ فارغًا عن قصد؛ لا يحتوي على أي صنف تجريبي أو رقم مُفترض.

**الملف:** `src/data/catalog.ts`

بداخله نموذج صنف مكتمل ضمن التعليقات. أضف أصنافك داخل المصفوفة:

```ts
export const PRODUCTS: Product[] = [
  {
    id: 'iphone-15-pro-max',
    name: 'آيفون ١٥ برو ماكس',
    brand: 'apple',
    brandName: 'أبل',
    category: 'phones',
    categoryName: 'الهواتف',
    images: ['/products/iphone-15-pro-max.jpg'],
    variants: [
      {
        id: 'v1',
        color: { name: 'تيتانيوم طبيعي', hex: '#C8C2B6' },
        storage: '256 غيغابايت',
        price: 68000,
        stock: 3,
      },
    ],
    warrantyMonths: 12,
    featured: true,
  },
];
```

**الصور** تُوضع في `public/products/`. ويرفض المتجر أي رابط صورة خارجي.

التصنيفات والعلامات التجارية **تُشتق تلقائيًا** من الأصناف الموجودة، فلا تظهر
فئة فارغة في أي موضع.

## ثانيًا: بياناتك

**الملف:** `src/config/store.ts`

| القيمة | الوصف |
| --- | --- |
| `whatsapp` | رقم الواتساب الذي تصله الطلبات (صيغة دولية بلا `+`) |
| `transferNumberLocal` | الرقم المعروض للعميل للتحويل عليه |
| `facebook` | رابط الصفحة |
| `shipping.fee` | قيمة الشحن |
| `shipping.freeOver` | حدّ الشحن المجاني (`null` لتعطيله) |
| `PAYMENT_CHANNELS` | وسائل السداد، ولكل منها `enabled` |

وسيلة «السداد نقدًا في المعرض» **معطّلة** ابتداءً؛ فعّلها إن كان لديك مقر
لاستقبال العملاء.

## رحلة الطلب

1. يختار العميل الصنف ويضيفه إلى السلة.
2. يُدخل بيانات الاستلام — مع تحقق من الاسم والهاتف والعنوان.
3. يختار وسيلة السداد:
   - **إنستاباي** أو **محفظة إلكترونية** → يظهر رقم التحويل، ويُدخل العميل
     الرقم الذي حوّل منه، وقيمة التحويل، ويرفق صورة الإيصال.
   - **الدفع عند الاستلام** → لا يُطلب إثبات.
4. يراجع الطلب ثم يؤكده.
5. **زر الواتساب** يرسل تفاصيل الطلب كاملة إلى رقمك: الأصناف، والمبالغ، وبيانات
   المستلِم، ووسيلة السداد، وبيانات التحويل. وحين يدعم المتصفح المشاركة، تُرسل
   **صورة الإيصال مع الرسالة في خطوة واحدة**.

## رسائل التأكيد — `/merchant`

صفحة للتاجر تصوغ رسالتين بالعربية الفصحى وترسلهما إلى رقم العميل:

- **استلام تحويل** — تأكيد استلام الحوالة والتحقق منها، بالمبلغ ورقم الطلب.
- **اعتماد طلب** — تأكيد اعتماد الطلب وبدء تجهيزه.

الصفحة لا تحفظ شيئًا ولا تصل إلى بيانات أحد؛ إنما تركّب نصًا وتفتح به الواتساب.

---

## الأمن والخصوصية

بيانات العميل الشخصية **لا تُحفظ** في أي مكان، وصورة الإيصال **لا تُرفع** إلى
أي خادم. سياسة أمن المحتوى تمنع أي مورد خارجي وأي نص برمجي أو نمط مضمَّن.
لا خطوط خارجية، ولا تتبّع، ولا حسابات.

التفصيل الكامل في **[SECURITY.md](SECURITY.md)** — ويشمل الحدود الصريحة لما
لا يستطيع بناء ساكن أن يفعله.

## لوحة الإدارة

على المسار `#/admin`. أول زيارة تطلب ضبط رمز، ثم يُطلب في كل جلسة.

| القسم | ما يفعله |
| --- | --- |
| لوحة القيادة | الإيراد والطلبات ومسارها، الأكثر مبيعًا، المخزون على الوشك |
| الأصناف | إضافة وتعديل وحذف ونسخ، بخياراتها وأسعارها وصورها ومواصفاتها |
| الطلبات | متابعة الحالة، تسجيل الطلبات الواردة على الواتساب، تأكيد للعميل |
| كروت الخصم | نسبة أو مبلغ أو شحن مجاني، بشروط ومدة وسقف وعدد استعمالات |
| رسائل الواتساب | صياغة رسائل التأكيد وإرسالها |
| الإعدادات | الاسم والرقم والشحن ووسائل السداد وحدّ تنبيه المخزون |
| النسخ والنشر | نسخة احتياطية، واستعادتها، وتصدير الأصناف إلى ملف الكتالوج |

### حدود لا بدّ من معرفتها

الموقع ثابت بلا خادم، وهذا يرتّب ثلاثة أمور:

1. **ما تضيفه محفوظ في متصفحك أنت.** ليراه الزوار، نزّل `catalog.ts` من صفحة
   «النسخ والنشر» وضعه مكان `src/data/catalog.ts` وارفعه، فيُبنى الموقع وينشر
   تلقائيًا.
2. **طلبات العملاء لا تصلك عبر اللوحة**، إنما على الواتساب كما هو الحال اليوم؛
   وتُسجَّل في اللوحة يدويًا. ولا تُحفظ بيانات عميل على جهازه إطلاقًا: دفتر
   الطلبات لا يعمل إلا على الجهاز الذي ضُبط عليه رمز الإدارة.
3. **رمز الإدارة يمنع العابر لا المُصمِّم.** الحماية الحقيقية تبدأ مع الخادم.

كل ذلك يزول عند الانتقال إلى استضافة ودومين: الشيفرة مبنية على عقود مستقلة عن
مصدر البيانات (`CatalogRepository` وواجهة `useStoreData`)، فيكفي استبدال جسم كل
دالة بنداء شبكة دون تعديل أي شاشة.

## بنية المشروع

```
src/
├── config/store.ts        القيم الافتراضية للتاجر ووسائل السداد
├── data/catalog.ts        بضاعة النشر — يُولَّد من لوحة الإدارة
├── data/storeData.ts      مصدر البيانات: الأصناف والكروت والطلبات والإعدادات
├── domain/                الأنواع وعقد الوصول إلى الكتالوج وكيانات الإدارة
├── admin/                 لوحة الإدارة كاملة، في حزمة منفصلة
├── store/stores.ts        السلة والمختارات وكرت الخصم والسمة
├── utils/coupons.ts       فحص كروت الخصم وحسابها
├── utils/security.ts      التحقق والتطهير
├── utils/whatsapp.ts      صياغة الرسائل
├── components/            الترويسة والتذييل والبطاقات
├── pages/                 الواجهة والمعروضات والصنف والسلة والسداد والتأكيد
└── styles/                نظام التصميم وأنماط اللوحة
```
