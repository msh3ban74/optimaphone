# OptimaPhone — أوبتيما فون 🛍️

**متجر التقنية الفاخر** — موقع ويب عربي بالكامل (من اليمين للشمال) لبيع الموبايلات واللابتوبات والإكسسوارات، بتصميم داكن/فاتح فاخر بلمسة ذهبية.

مبني بـ Vite + React + TypeScript (strict) — بدون أي مكتبات واجهة جاهزة: نظام تصميم مخصوص بالكامل.

## المميزات

| الصفحة | المحتوى |
| --- | --- |
| **الرئيسية** | واجهة سينمائية بإضاءة ذهبية متحركة، عروض فلاش بعدّاد تنازلي حي، وصل حديثًا، التشكيلات، الأكثر رواجًا، شاهدتها مؤخرًا |
| **المتجر** | بحث فوري + فلاتر (الفئة / الماركة / السعر / العروض) + 5 طرق ترتيب — كلها في رابط الصفحة فتقدر تشاركها |
| **صفحة المنتج** | معرض صور، اختيار اللون والمساحة والسعر يتغيّر مباشرة، حاسبة تقسيط 0%، مواصفات تقنية، آراء عملاء موثّقين، منتجات مشابهة |
| **السلة** | بتتحفظ تلقائيًا في المتصفح، أكواد خصم شغالة (`WELCOME10`, `OPTIMA50`, `GOLD15`)، شحن مجاني فوق $200 |
| **إتمام الطلب** | 4 خطوات بالتحقق من البيانات (العنوان ← التوصيل ← الدفع ← المراجعة) وصفحة تأكيد متحركة |
| **المفضلة** | حفظ المنتجات بقلب بينبض ❤️ |

+ وضع داكن/فاتح بزرار واحد، وكل البيانات (السلة، المفضلة، الطلبات) بتفضل محفوظة حتى بعد قفل المتصفح.

## التشغيل محليًا

```bash
npm install
npm run dev       # سيرفر التطوير — يفتح على localhost
npm run build     # فحص الأنواع + بناء نسخة الإنتاج في dist/
npm run preview   # تشغيل نسخة الإنتاج محليًا
```

## النشر على الإنترنت (مرة واحدة)

المستودع فيه GitHub Actions بيبني وينشر تلقائيًا مع كل تعديل. فعّله مرة واحدة:

1. من صفحة المستودع: **Settings ← Pages**
2. تحت **Source** اختار: **GitHub Actions**

وخلاص — الموقع هيبقى متاح على رابط `github.io` الخاص بك ويتحدّث تلقائيًا مع كل push.

## بنية الكود

```
src/
├── domain/       # الأنواع + عقود الوصول للبيانات (جاهزة للربط بسيرفر حقيقي)
├── data/         # كتالوج المنتجات + مستودع البيانات المحلي
├── store/        # حالة التطبيق (سلة/مفضلة/طلبات/ثيم) مع حفظ تلقائي
├── components/   # الهيدر والفوتر وكروت المنتجات والعناصر المشتركة
├── pages/        # الرئيسية، المتجر، المنتج، السلة، إتمام الطلب، التأكيد، المفضلة
├── styles/       # نظام التصميم الكامل (متغيرات، ثيمات، أنيميشن، تجاوب)
└── utils/        # تنسيق الأسعار والعدّادات
```

المنتجات حاليًا بيانات تجريبية منسّقة جوه `src/data/catalog.ts` — عدّلها براحتك، وطبقة البيانات معمولة بحيث تتبدّل بسيرفر حقيقي لاحقًا من غير تغيير أي صفحة.
